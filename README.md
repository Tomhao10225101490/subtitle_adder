# 字幕加加

把视频拖进浏览器，本地识别语音，改好字幕，再导出已经烧进画面的 MP4。

```
拖入视频 → Whisper 本地识别 → 改文字 / 时间 / 样式 → 导出带字幕的成片
```

视频不会上传。内部始终保存成可编辑的字幕数据，只有点「烧录并下载」才会把字幕压进画面。

## 环境要求

- Node.js 18 或更高（推荐 22）
- 桌面浏览器：**Chrome 或 Edge**（识别更快、导出 MP4 更稳）
- Firefox 可用，但部分机器会走较慢的导出路径
- Safari 可能没有 WebCodecs，导出更容易变成较慢的 WebM
- 第一次自动识别需要能访问 Hugging Face，用来下载 Whisper 模型（大约 286–463 MB）。下载完成后缓存在浏览器里，之后可以离线识别

## 安装和启动

```sh
git clone https://github.com/Tomhao10225101490/subtitle_adder.git
cd subtitle_adder
npm install
npm run dev
```

浏览器打开 [http://localhost:4321](http://localhost:4321)。

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 开发模式，改代码会自动刷新 |
| `npm run build` | 打成静态网站到 `dist/` |
| `npm run preview` | 预览打包结果 |
| `npm test` | 跑工程文件 / 拆分合并 / SRT 的基本检查 |

## 完整使用流程

### 1. 打开视频

任选一种方式：

- 把 MP4 / MOV / WebM 拖到首页虚线框
- 点「选择视频」
- 点「试用示例视频」先走一遍流程（自带几句示例字幕，不用等识别）

MKV 浏览器播不了，先转成 MP4：

```sh
ffmpeg -i input.mkv -c copy out.mp4
```

### 2. 生成字幕

- 选好「识别语言」，再点 **自动识别**
- 第一次会下载模型，进度条会显示下载和识别状态
- 识别完成后，右侧列表和时间轴都会出现字幕
- 如果你已经有字幕文件，点 **导入 SRT/VTT**，或把 `.srt` / `.vtt` 拖进页面

识别不准是正常的。浏览器里的 Whisper-small 比桌面版 large-v3 更容易认错，所以下一步就是改。

### 3. 修改字幕

每一条都可以改：

- **文字**：直接在输入框里改错字
- **时间**：改开始秒、结束秒
- **点某一行**：预览跳到这句
- **点时间轴色块**：同样会跳转并选中
- **拆分**：先选中一句，把播放头拖到要切开的位置，再点「拆分」（中文按字切，英文按单词切）
- **合并**：选中一句，与它的下一句合并
- **删除 / 加一行**：增删字幕
- **撤销 / 重做**：点按钮，或在输入框**外面**按 `Ctrl+Z` / `Ctrl+Shift+Z`（Mac 用 `⌘Z` / `⌘⇧Z`）。在输入框里按这些键，走的是浏览器自己的文字撤销，不会整段字幕被撤掉

改的只是工程数据，**不会改你的原始视频文件**。

### 4. 调样式

右侧「样式」可以改字体、字号、颜色、描边、背景框、位置、对齐、阴影、动画。

预设包括：底部白字、霓虹描边、大字描边、逐词高亮、电影字幕。改过任意一项后会变成「自定义」。

预览画面上看到的字幕，就是烧录进成片时的样子。

### 5. 导出

| 按钮 | 得到什么 |
| --- | --- |
| 导出 SRT | `{原名}.srt`，给剪辑软件或播放器当软字幕 |
| 导出 VTT | `{原名}.vtt`，给网页播放器用 |
| 保存工程 | `{原名}.project.json`，保存字幕、样式、原视频文件名 |
| 烧录并下载 | `{原名}_captioned.mp4`（个别浏览器可能是 `.webm`），字幕已经画在画面上 |

烧录时请保持这个标签页在前台。切到后台会暂停，回来后继续。

MP4 / MOV 会尽量走浏览器硬件编码（通常比实时更快）。其他格式会走较慢的逐帧录制。

## 工程文件

`*.project.json` **不包含视频本身**，只记录：

- 每条字幕的文字和时间
- 当前样式
- 原来的视频文件名和时长
- 识别语言

再次打开：

1. 点「打开工程」，选 `.project.json`
2. 如果还没打开视频，会提示你再选一次当时的那个视频
- 也可以直接把 `.project.json` 拖到首页

换了一个不同的视频文件也能载入字幕，但时间轴可能对不齐，需要自己检查。

## 常见问题

**识别很慢，或第一次卡住**  
第一次在下载几百 MB 的模型。没有独显 / 不支持 WebGPU 时会走 CPU，一分钟视频可能要跑好几分钟。用 Chrome，并保持标签页开着。

**识别结果是英文乱码或重复句子**  
确认「识别语言」选对了。改完字再导出。实在太差，可以先用别的工具出 SRT，再导入进来烧录。

**点了烧录没有 MP4**  
看浏览器下载栏。Safari 或旧版 Firefox 可能下到 `.webm`。换 Chrome 再试。

**烧录完预览没声音**  
点预览旁边的喇叭按钮。如果仍没有，刷新页面重新打开视频（原始文件还在你电脑上）。

**中文拆分把整句复制成两句**  
已经按字符切开。请先把播放头放到那一句中间，再点「拆分」。句子太短（不到 0.4 秒）不会拆。

## 明确做不到的事

- 不会自动翻译成另一门语言
- 不会在云端跑 large-v3
- 不会当 Premiere / 达芬奇那样的多轨道剪辑器
- 超长 4K 视频可能把内存吃满，建议先切成片段

## 隐私

识别、预览、烧录都在你这台电脑的浏览器里完成。这个仓库没有账号系统，也没有把视频传到服务器的代码。

模型文件来自 Hugging Face 的 `onnx-community/whisper-small_timestamped`。
